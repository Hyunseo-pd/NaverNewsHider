BetterNaver 개인정보처리방침

시행일: 2026년 6월 2일

BetterNaver는 사용자의 개인정보를 수집, 판매 또는 제3자에게 제공하지 않습니다.

수집 또는 저장되는 정보

BetterNaver는 네이버 화면에서 사용자가 선택한 일부 영역을 숨기기 위한 Chrome 확장 프로그램입니다. 확장 프로그램은 기능 제공을 위해 사용자의 설정값을 Chrome 저장소에 저장할 수 있습니다.

  • 뉴스 숨기기 여부
  • 쇼핑 숨기기 여부
  • 피드 숨기기 여부
  • 날씨, 증시, 위젯 등 사이드바 항목 숨기기 여부
  • 로그인 영역 숨기기 여부
  • 팝업 메뉴 접기/펼치기 상태

수집하지 않는 정보

BetterNaver는 이름, 이메일 주소, 전화번호, 결제 정보, 계정 정보, 검색어, 방문 기록, 쿠키, 비밀번호를 수집하지 않습니다.

정보 사용 목적

저장된 설정값은 확장 프로그램 기능 제공과 사용자 설정 유지에만 사용됩니다.

제3자 제공 및 외부 전송

BetterNaver는 사용자 데이터를 외부 서버로 전송하지 않으며, 광고나 추적 목적으로 사용하지 않습니다.

데이터 삭제

사용자는 Chrome 확장 프로그램을 삭제하거나 브라우저 저장 데이터를 삭제하여 저장된 설정값을 제거할 수 있습니다.
